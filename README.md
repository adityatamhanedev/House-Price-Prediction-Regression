# 🏠 House Price Prediction using Regression Models

## 📌 Project Overview

This project predicts house prices using Machine Learning regression models. It uses housing features such as area, bedrooms, location, and furnishing to estimate the market price of a property.

The project demonstrates real-world Machine Learning workflow including:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Model Evaluation
- Price Prediction
- Visualization

---

## 🎯 Problem Statement

House prices vary based on multiple features such as location, size, and property condition. Accurately estimating property price is important for:

- Buyers
- Sellers
- Real estate agents
- Banks
- Investors

This project builds regression models to predict housing prices based on property attributes.
